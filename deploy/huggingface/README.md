# Spotafriend

Find your people through the music you love. Add a playlist, get matched with people whose
music sounds like yours, and start a live chat.

Source code: https://github.com/yukezhaoyz/spotafriend

This Space builds from the GitHub repository (see `Dockerfile`). Live matching and chat run on
Amazon Web Services (AWS) AppSync; its settings are stored as this Space's secrets.
